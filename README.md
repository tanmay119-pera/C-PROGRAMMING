Every folder is self-contained with well-commented source code, dedicated README guides, and hands-on exercises designed to solidify core computer science principles.

## 💻 How to Compile & Run

### 📋 Prerequisites
* Standard C compiler: **Clang** (default on macOS) or **GCC** (Linux/Windows)
* Integrated Editor: **Visual Studio Code**

### ⚙️ Compilation Examples

Open your terminal in the root directory:

```bash
# 🔹 1. Compile any Chapter practice file
clang -Wall -Wextra -std=c99 CH-07-Pointers/pointers.c -o pointers_app
./pointers_app

# 🔹 2. Compile an Advanced Capstone Project
clang -Wall -Wextra -std=c99 PROJECT-10/Dyanmic-Task-Board.C -o taskboard_app
./taskboard_app
```

## 🛡️ Professional C Development Rules

<table>
  <tr>
    <td width="50%">
      <h4>🧹 1. Buffer Sanitization</h4>
      <p>Always consume leftover newline (<code>\n</code>) characters using a <code>getchar()</code> loop when switching from numeric <code>scanf()</code> to string <code>fgets()</code>.</p>
    </td>
    <td width="50%">
      <h4>🔒 2. Memory Safety (DMA)</h4>
      <p>Never assume <code>malloc()</code> succeeded. Always verify <code>ptr != NULL</code> and immediately assign <code>ptr = NULL;</code> after calling <code>free()</code>.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h4>🗄️ 3. Safe Stream Management</h4>
      <p>Always pair <code>fopen()</code> with <code>fclose()</code> to flush operating system stream buffers and prevent file descriptor resource leaks.</p>
    </td>
    <td width="50%">
      <h4>⚡ 4. Compiler Warnings</h4>
      <p>Always compile with <code>-Wall -Wextra</code> to catch subtle type mismatches, unused variables, and uninitialized pointers during compilation.</p>
    </td>
  </tr>
</table>
